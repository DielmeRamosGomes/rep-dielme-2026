2. INTRODUÇÃO E CONCEITO
--------------------------------------------------------------------------------
Modelos de Machine Learning e Inteligência Artificial funcionam por meio de operações 
matemáticas (soma, multiplicação de matrizes, cálculo de vetores). Portanto, eles não 
conseguem processar diretamente valores em texto como "Azul", "São Paulo" ou "Superior".

Para que um modelo possa aprender com dados qualitativos, precisamos transformar essas 
categorias em números de forma estruturada.

O que são Variáveis Categóricas?
São características que representam grupos, classes ou qualidades.
Exemplos:
  - Cor: [Azul, Verde, Vermelho] (Nominal - sem ordem inerente)
  - Cidade: [São Paulo, Recife, Curitiba] (Nominal - sem ordem inerente)
  - Escolaridade: [Fundamental, Médio, Superior] (Ordinal - possui ordem natural)


3. TÉCNICAS DE CODIFICAÇÃO (ENCODING)
--------------------------------------------------------------------------------

A) LABEL ENCODING (Codificação de Rótulos)
   - Como funciona: Atribui um número inteiro exclusivo para cada categoria.
   - Exemplo:
       Azul     -> 0
       Verde    -> 1
       Vermelho -> 2
   - Vantagens:
     * Extremamente simples e direto.
     * Não aumenta a quantidade de colunas no conjunto de dados (pouco consumo de memória).
   - Limitações:
     * Pode criar uma ORDEM ARTIFICIAL onde ela não existe. Por exemplo, o algoritmo pode 
       interpretar que Vermelho (2) é maior ou "duas vezes superior" a Azul (0), 
       distorcendo o aprendizado.
   - Indicação: Deve ser usado prioritariamente para variáveis categóricas ordinais 
     (ex.: Fundamental = 1, Médio = 2, Superior = 3).

B) ONE-HOT ENCODING (Conversão de Variáveis)
   - Como funciona: Cria uma nova coluna binária (0 ou 1) para cada categoria existente.
   - Exemplo (Variável Cor):
       Registro | Cor_Azul | Cor_Verde | Cor_Vermelho
       ---------------------------------------------
       Azul     |    1     |     0     |      0
       Verde    |    0     |     1     |      0
       Vermelho |    0     |     0     |      1
   - Vantagens:
     * Evita completamente o problema da ordem artificial.
     * Ideal para categorias nominais (sem hierarquia).
   - Limitações:
     * Aumenta a quantidade de colunas (Inflação de Dimensionalidade).


4. O DESAFIO DA INFLAÇÃO DE DIMENSIONALIDADE
--------------------------------------------------------------------------------
Quando aplicamos One-Hot Encoding em variáveis com alta cardinalidade (muitas categorias 
diferentes), o número de colunas do conjunto de dados dispara.

Exemplo Prático:
Se a variável "Cidade" contiver 500 cidades diferentes, a aplicação de One-Hot Encoding 
gerará 500 novas colunas na sua tabela.

Consequências do Aumento Excessivo de Dimensões:
1. Alto custo computacional (maior consumo de RAM e CPU/GPU).
2. Treinamento do modelo fica significativamente mais lento.
3. Risco elevado de Overfitting (o modelo decora os dados de treino mas falha ao generalizar).

Estratégias para reduzir a dimensionalidade:
- Agrupar categorias raras ou pouco frequentes em um grupo genérico ("Outros").
- Codificação por Frequência (substituir a categoria pelo percentual ou contagem de vezes 
  que aparece).
- Combinar categorias com significados similares.
- Aplicar técnicas de Redução de Dimensionalidade (ex: PCA - Principal Component Analysis).


5. PRÁTICA GUIADA (EXEMPLO EM PYTHON COM PANDAS)
--------------------------------------------------------------------------------
Abaixo está o código-fonte de um exercício prático para analisar a relação entre variáveis 
e identificar redundâncias.

```python
import pandas as pd

# Passo 1: Criando o conjunto de dados simples
dados = pd.DataFrame({
    "horas_estudo": [1, 2, 3, 4, 5],
    "nota_anterior": [2, 4, 6, 8, 10]
})

print("--- Tabela de Dados ---")
print(dados)

# Passo 2: Verificando a matriz de correlação
print("
--- Matriz de Correlação ---")
print(dados.corr())
```

Perguntas para Reflexão:
1. O valor de correlação entre 'horas_estudo' e 'nota_anterior' está próximo de 1?
   -> Resposta: Sim, o valor é exatamente 1.0 (correlação perfeita).
2. O que isso indica?
   -> Indica que uma variável cresce em proporção exata à outra.
3. Elas carregam informações redundantes?
   -> Sim. Nesse caso, manter ambas pode gerar duplicidade de peso no modelo.
   -> Solução: Remover uma das colunas, combiná-las ou aplicar redução de dimensionalidade.


6. EXERCÍCIO DE FIXAÇÃO / PAUSE E RESPONDA
--------------------------------------------------------------------------------
Pergunta: Qual é o principal risco de usar Label Encoding em categorias sem ordem natural?

[A] Diminuir o número de variáveis.
[B] Eliminar a necessidade de normalização.
[C] Criar uma ordem artificial entre categorias.  <-- (RESPOSTA CORRETA)
[D] Reduzir o tamanho do dataset.

Explicação: Como o Label Encoding atribui inteiros sequenciais (0, 1, 2...), algoritmos 
baseados em cálculo de distância ou regressão podem assumir que uma categoria tem valor 
quantitativo maior que a outra, gerando viés indevido.
